# Built-in 2D Array — Java

A simple Java program demonstrating the use of a **built-in 2D array** for storing and processing data in rows and columns.

## Concepts Used

* 2D Arrays
* Rows and Columns
* Array Declaration and Initialization
* Nested Loops
* Array Traversal
* Java Basics

## Operations

The program demonstrates:

* Creating a 2D array
* Storing values in rows and columns
* Accessing array elements
* Traversing the array using nested loops
* Displaying the elements of the array
